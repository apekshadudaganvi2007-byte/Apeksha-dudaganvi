# 🤖 Voice Controlled AI Robot

An open-source robotic project that combines **Artificial Intelligence** and **Voice Recognition** to let users control hardware movements and query information using natural spoken commands.

---

##  Features

* Real-Time Speech Recognition: Converts spoken commands into text instantly using advanced ASR models.
* AI-Powered NLP: Processes user intent (using LLMs or intent classification) to understand context beyond rigid command words.
* Autonomous & Manual Modes: Switch seamlessly between voice-driven navigation and autonomous obstacle avoidance.
* Hardware Integration: Compatible with microcontrollers like Raspberry Pi and Arduino.

---

##  Tech Stack

* Programming Language:** Python, C++
* AI / Machine Learning:** OpenAI Whisper / SpeechRecognition, OpenCV (for vision, if applicable)
* Hardware: Raspberry Pi 4 / Arduino Uno, Motor Driver (L298N), USB Microphone, Ultrasonic Sensors
* Communication: MQTT / Serial Communication
